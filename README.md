# JS Communication — download files

Download this branch using GitHub Code > Download ZIP, then extract it.

- For Cloudflare Pages Direct Upload, drag the cloudflare-site folder into the uploader.
- Alternatively download js-communication-cloudflare.zip and upload that ZIP directly to Pages.
- For an interactive preview without installation, download js-communication-preview.html and open it in a normal browser.

The files are prebuilt. No npm command, backend, database or secrets are needed.
